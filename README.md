## 🇨🇴 Español

### ¿Qué es Nimbos GEO?

**Nimbos GEO** es una plataforma de inteligencia satelital B2B diseñada para ofrecer vigilancia ambiental, agrícola y ganadera automatizada en el corredor Caribe (Barranquilla – Santa Marta – Cartagena). Utilizando **imágenes multiespectrales de Sentinel-2 (ESA/Copernicus)** procesadas mediante Google Earth Engine y un pipeline totalmente automatizado en Linux y GitHub Actions, entregamos analítica de alta precisión con un costo operativo cercano a cero.

### Propuesta de Valor — El Enfoque de Doble Anillo

A diferencia de los monitoreos tradicionales en campo, Nimbos GEO implementa una geometría analítica concéntrica para cada cliente (fincas, plantaciones, reservas o constructoras):
1. **Zona Núcleo (Espejo de agua / Lote):** Cálculo de **MNDWI** (*Modified Normalized Difference Water Index*) para control hídrico de alta precisión en jagüeyes, embalses y ciénagas.
2. **Anillo Perimetral (Buffer 100m - 500m):** Cálculo de **NDVI** y **NDMI** (*Normalized Difference Moisture Index*) para detectar estrés hídrico y sequía en pasturas o cultivos antes de que sea visible a simple vista.
3. **Monitoreo de Incendios y Calor:** Integración del índice **NBR** (*Normalized Burn Ratio*) y cruce con anomalías térmicas (**NASA FIRMS**) para mitigación de riesgos de incendios forestales.
